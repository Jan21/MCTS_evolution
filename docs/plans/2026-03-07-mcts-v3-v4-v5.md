## Task 2: Implement V3 — Constraint-Context MCTS with Deep No-Good Learning

**Files:**
- Create: `MCTS/v3.py`

**Spec:** `prompts/algorithms/v3_constraint_context.md`

**Key V3 concepts to implement:**

1. **Constraint store** on each MCTS node: list of commitment objects (`BlockReq`, `ProtectReq`, `SupportReq`) each tied to a decision ID.
2. **No-good table**: set of `(context_signature, forbidden_action)` entries. Context signature = frozenset of `(robot_color, position, commitment_type)`. A no-good applies when the current context is a **superset** of the no-good's context.
3. **Decision history**: ordered list of `(decision_id, action, commitments_added)` for backjumping.
4. **Backjumping during rollout**: on conflict, identify the culprit decision (most recent decision in conflict set), record a no-good, and backjump to try a different action.
5. **No-good filtering during expansion**: skip actions that match no-goods for the current context.
6. **Disjunctive SupportReq**: lazy commitment — create `SupportReq` with multiple choices, defer commitment until forced.
7. **Dead node propagation**: if all children filtered by no-goods, mark node dead; propagate upward.
8. **Backjump-aware backup**: cost attributed only to path from root to culprit, not full path.

# ---------------------------------------------------------------------------
# V3 Commitment types
# ---------------------------------------------------------------------------

@dataclass(frozen=True)
class BlockReq:
    """Robot must be at position to serve as blocker for segment."""
    robot_color: str
    position: tuple
    segment_id: str
    decision_id: int

@dataclass(frozen=True)
class ProtectReq:
    """Robot must not be moved (added lazily on conflict)."""
    robot_color: str
    position: tuple
    segment_id: str
    decision_id: int

@dataclass(frozen=True)
class SupportReq:
    """Segment needs one of several (robot_color, position) options."""
    segment_id: str
    choices: tuple  # tuple of (robot_color, position) pairs (frozen for hashing)
    chosen: tuple | None  # (robot_color, position) or None
    decision_id: int

@dataclass(frozen=True)
class NoGood:
    """A no-good: given this context signature, this action is forbidden."""
    context_sig: frozenset  # frozenset of (robot_color, position, commitment_type)
    forbidden_action: tuple  # action key


# ---------------------------------------------------------------------------
# V3 MCTS Node
# ---------------------------------------------------------------------------

@dataclass
class MCTSNode:
    plan: PartialPlan
    parent: MCTSNode | None
    action: tuple | None
    children: list[MCTSNode] = field(default_factory=list)
    visit_count: int = 0
    total_cost: float = 0.0
    # V3: constraint store
    constraints: list = field(default_factory=list)  # list of BlockReq/ProtectReq/SupportReq
    dead: bool = False

    @property
    def avg_cost(self) -> float:
        if self.visit_count == 0:
            return float("inf")
        return self.total_cost / self.visit_count


# ---------------------------------------------------------------------------
# V3 Context signature helpers
# ---------------------------------------------------------------------------

def _context_signature(constraints):
    """Compute hashable context signature from constraint list."""
    sig = set()
    for c in constraints:
        if isinstance(c, BlockReq):
            sig.add((c.robot_color, c.position, "block"))
        elif isinstance(c, ProtectReq):
            sig.add((c.robot_color, c.position, "protect"))
        elif isinstance(c, SupportReq):
            if c.chosen is not None:
                sig.add((c.chosen[0], c.chosen[1], "support"))
            else:
                # Use segment_id as proxy for uncommitted support
                sig.add((c.segment_id, None, "support_open"))
    return frozenset(sig)


def _nogood_applies(nogood_sig, current_sig):
    """A no-good applies if current context is a superset of the no-good's context."""
    return nogood_sig.issubset(current_sig)


def _extract_commitments_from_subgoal(subgoal, segment_id, decision_id, state):
    """Extract BlockReq and SupportReq from a subgoal application."""
    commitments = []
    # BlockReq: support robot must be at support position
    commitments.append(BlockReq(
        robot_color=subgoal.support.color,
        position=subgoal.support.position,
        segment_id=segment_id,
        decision_id=decision_id,
    ))
    # SupportReq: helper needs to reach support position; multiple helpers could serve
    choices = tuple(
        (h.color, h.position) for h in state.helpers
        if h.color != subgoal.support.color
    )
    if choices:
        commitments.append(SupportReq(
            segment_id=segment_id,
            choices=choices,
            chosen=None,
            decision_id=decision_id,
        ))
    return commitments


def _check_conflicts(constraints):
    """Check all pairs of commitments for conflicts.

    Returns: list of conflict sets (each a frozenset of conflicting commitments).
    """
    conflicts = []
    blocks = [c for c in constraints if isinstance(c, BlockReq)]
    # Position conflict: same robot, different positions
    by_color = {}
    for b in blocks:
        by_color.setdefault(b.robot_color, []).append(b)
    for color, reqs in by_color.items():
        positions = {r.position for r in reqs}
        if len(positions) > 1:
            conflicts.append(frozenset(reqs))

    # SupportReq exhaustion: all choices eliminated by blocks
    for c in constraints:
        if isinstance(c, SupportReq) and c.chosen is None:
            blocked_positions = {
                (b.robot_color, b.position) for b in blocks
            }
            remaining = [ch for ch in c.choices if ch not in blocked_positions]
            if not remaining:
                conflicts.append(frozenset({c}))

    return conflicts


def _find_culprit(conflict_set):
    """Find the most recent decision in the conflict set."""
    max_id = -1
    culprit = None
    for c in conflict_set:
        if hasattr(c, 'decision_id') and c.decision_id > max_id:
            max_id = c.decision_id
            culprit = c
    return culprit, max_id

# MCTS_V3 -- Constraint-Context with Deep No-Good Learning
# ---------------------------------------------------------------------------

class MCTS_V3(MCTS):

    def __init__(self, cfg=None):
        if cfg is None:
            cfg = OmegaConf.load(
                Path(__file__).resolve().parent.parent / "conf" / "v3.yaml")
        self.cfg = cfg

    def solve(self, grid_env: GridEnv, state: State) -> SolveResult:
        self._cnt = _counter()
        self._best_cost = float("inf")
        self._best_plan = None
        self._start_time = time.monotonic()
        self._all_plans = []
        self._iteration = 0
        self._node_count = 0
        self._rollout_count = 0
        self._nogoods: list[NoGood] = []
        self._decision_counter = 0

        root_plan = _build_initial_plan(state, grid_env)
        root = MCTSNode(plan=root_plan, parent=None, action=None)

        for _ in range(self.cfg.max_iterations):
            self._iteration += 1
            node = self._select(root)

            if node.dead:
                self._backprop(node, self.cfg.penalty_cost)
                continue

            if node.plan.is_complete():
                cost = self._eval_complete(node.plan, grid_env)
                self._backprop(node, cost)
                continue

            child = self._expand(node, grid_env, state)
            if child is None:
                self._backprop(node, self.cfg.penalty_cost)
                continue

            cost = self._rollout(child, grid_env, state)
            self._backprop(child, cost)

        best = (self._best_plan if self._best_plan is not None
                else self._fallback(root, grid_env, state))
        return SolveResult(best_plan=best, all_plans=self._all_plans)

    def _next_decision_id(self):
        self._decision_counter += 1
        return self._decision_counter

    # -- No-good filtering --

    def _is_nogood(self, action_key, constraints):
        """Check if action is forbidden by any no-good in the current context."""
        current_sig = _context_signature(constraints)
        for ng in self._nogoods:
            if ng.forbidden_action == action_key:
                if _nogood_applies(ng.context_sig, current_sig):
                    return True
        return False

    def _add_nogood(self, context_sig, action_key):
        """Record a no-good with subsumption check."""
        new_ng = NoGood(context_sig=context_sig, forbidden_action=action_key)
        if self.cfg.nogood_subsumption:
            # Remove subsumed no-goods (same action, larger context)
            self._nogoods = [
                ng for ng in self._nogoods
                if not (ng.forbidden_action == action_key
                        and context_sig.issubset(ng.context_sig))
            ]
        self._nogoods.append(new_ng)
        # Bound table size
        if len(self._nogoods) > self.cfg.max_nogoods:
            self._nogoods = self._nogoods[-self.cfg.max_nogoods:]

    # -- Selection (LCB with no-good pruning + dead detection) --

    def _select(self, node: MCTSNode) -> MCTSNode:
        while node.children:
            if node.dead:
                return node
            if self._can_expand(node):
                return node
            alive = [c for c in node.children if not c.dead]
            if not alive:
                node.dead = True
                return node
            viable = [c for c in alive
                      if c.plan.cost() <= self._best_cost]
            if not viable:
                return node
            node = min(viable, key=lambda c: self._lcb(c, node))
        return node

    def _lcb(self, child: MCTSNode, parent: MCTSNode) -> float:
        if child.visit_count == 0:
            return float("-inf")
        exploit = child.avg_cost
        explore = self.cfg.ucb_exploration * math.sqrt(
            math.log(parent.visit_count + 1) / child.visit_count)
        return exploit - explore

    def _can_expand(self, node: MCTSNode) -> bool:
        k = math.ceil(
            self.cfg.pw_C * (max(node.visit_count, 1) ** self.cfg.pw_alpha))
        return len(node.children) < k

    # -- Expansion with no-good filtering --

    def _expand(self, node: MCTSNode, grid_env: GridEnv, state: State):
        plan = node.plan
        open_edges = plan.open_edges()
        if not open_edges:
            return None

        parent_id, child_id = max(
            open_edges, key=lambda e: plan.g.edges[e]["cost"] or 0)

        candidates = _get_candidates(plan, parent_id, state, grid_env)
        if not candidates:
            return None

        candidates.sort(key=lambda x: x[1])

        tried = {c.action for c in node.children}
        for subgoal, _score, parent_sp in candidates:
            action_key = (parent_id, child_id,
                          subgoal.bottleneck.position,
                          subgoal.support.position,
                          subgoal.helper.color,
                          parent_sp)
            if action_key in tried:
                continue

            # V3: no-good filtering
            if self._is_nogood(action_key, node.constraints):
                continue

            child_plan = _copy_plan(plan)
            result = _apply_subgoal(
                child_plan, parent_id, child_id,
                subgoal, grid_env, self._cnt,
                parent_support_pos=parent_sp)
            if result is None:
                continue

            for pid, cid in list(child_plan.open_edges()):
                _try_close_edge(child_plan, pid, cid, grid_env)

            # V3: build child constraints
            decision_id = self._next_decision_id()
            seg_id = f"{parent_id}->{child_id}"
            child_constraints = list(node.constraints)
            new_commitments = _extract_commitments_from_subgoal(
                subgoal, seg_id, decision_id, state)
            child_constraints.extend(new_commitments)

            # V3: check for conflicts
            conflict_sets = _check_conflicts(child_constraints)
            if conflict_sets and self.cfg.backjump_enabled:
                # Record no-goods for each conflict
                for cs in conflict_sets:
                    culprit, cid_val = _find_culprit(cs)
                    if culprit is not None:
                        ctx = [c for c in child_constraints
                               if hasattr(c, 'decision_id')
                               and c.decision_id < cid_val]
                        ctx_sig = _context_signature(ctx)
                        self._add_nogood(ctx_sig, action_key)
                # Still create the node but it may have high cost
                pass

            child_node = MCTSNode(
                plan=child_plan, parent=node, action=action_key,
                constraints=child_constraints)
            self._node_count += 1
            node.children.append(child_node)
            self._check_complete(child_plan, grid_env)
            return child_node

        return None

    # -- Rollout with constraint propagation + backjumping --

    def _rollout(self, node: MCTSNode, grid_env: GridEnv, state: State):
        self._rollout_count += 1
        plan = _copy_plan(node.plan)
        constraints = list(node.constraints)
        decision_history = []  # (decision_id, action_key, commitments)

        for _ in range(self.cfg.max_rollout_depth):
            for pid, cid in list(plan.open_edges()):
                _try_close_edge(plan, pid, cid, grid_env)

            open_edges = plan.open_edges()
            if not open_edges:
                break

            # Pick highest-cost open edge
            parent_id, child_id = max(
                open_edges, key=lambda e: plan.g.edges[e]["cost"] or 0)

            candidates = _get_candidates(plan, parent_id, state, grid_env)
            if not candidates:
                return self.cfg.penalty_cost

            # Filter by no-goods
            filtered = []
            for subgoal, score, parent_sp in candidates:
                action_key = (parent_id, child_id,
                              subgoal.bottleneck.position,
                              subgoal.support.position,
                              subgoal.helper.color,
                              parent_sp)
                if not self._is_nogood(action_key, constraints):
                    filtered.append((subgoal, score, parent_sp))

            if not filtered:
                # All candidates filtered — try without filtering
                filtered = candidates

            # Pick from top half by score
            filtered.sort(key=lambda x: x[1])
            pick_from = max(1, len(filtered) // 2)
            subgoal, _, parent_sp = random.choice(filtered[:pick_from])

            action_key = (parent_id, child_id,
                          subgoal.bottleneck.position,
                          subgoal.support.position,
                          subgoal.helper.color,
                          parent_sp)

            result = _apply_subgoal(
                plan, parent_id, child_id,
                subgoal, grid_env, self._cnt,
                parent_support_pos=parent_sp)
            if result is None:
                continue

            # Record decision and commitments
            decision_id = self._next_decision_id()
            seg_id = f"{parent_id}->{child_id}"
            new_commitments = _extract_commitments_from_subgoal(
                subgoal, seg_id, decision_id, state)
            constraints.extend(new_commitments)
            decision_history.append((decision_id, action_key, new_commitments))

            # Check for conflicts
            conflict_sets = _check_conflicts(constraints)
            if conflict_sets and self.cfg.backjump_enabled:
                for cs in conflict_sets:
                    culprit, cid_val = _find_culprit(cs)
                    if culprit is not None:
                        ctx = [c for c in constraints
                               if hasattr(c, 'decision_id')
                               and c.decision_id < cid_val]
                        ctx_sig = _context_signature(ctx)
                        # Find the action of the culprit decision
                        for d_id, d_action, d_commits in decision_history:
                            if d_id == cid_val:
                                self._add_nogood(ctx_sig, d_action)
                                break
                # Return penalty — backjumping means this rollout is abandoned
                return self.cfg.penalty_cost

        for pid, cid in list(plan.open_edges()):
            _try_close_edge(plan, pid, cid, grid_env)

        if plan.is_complete():
            self._check_complete(plan, grid_env)
            cost = evaluate_plan(plan, grid_env)
            if cost is not None:
                return cost

        return plan.cost()

    # -- Backpropagation --

    def _backprop(self, node: MCTSNode, cost: float):
        while node is not None:
            node.visit_count += 1
            node.total_cost += cost
            node = node.parent

    # -- Helpers --

    def _eval_complete(self, plan, grid_env):
        cost = evaluate_plan(plan, grid_env)
        if cost is not None:
            if cost < self._best_cost:
                self._best_cost = cost
                self._best_plan = _copy_plan(plan)
            self._all_plans.append(PlanEntry(
                plan=_copy_plan(plan), cost=cost,
                stats=PlanStats(
                    wall_time=time.monotonic() - self._start_time,
                    iteration=self._iteration,
                    node_count=self._node_count,
                    rollout_count=self._rollout_count)))
            return cost
        return self.cfg.penalty_cost

    def _check_complete(self, plan, grid_env):
        if plan.is_complete():
            self._eval_complete(plan, grid_env)

    def _fallback(self, root, grid_env, state):
        best_node = root
        stack = [root]
        while stack:
            n = stack.pop()
            if n.visit_count > 0 and n.avg_cost < best_node.avg_cost:
                best_node = n
            stack.extend(n.children)
        plan = _copy_plan(best_node.plan)
        for _ in range(self.cfg.max_rollout_depth):
            open_edges = plan.open_edges()
            if not open_edges:
                break
            parent_id, child_id = max(
                open_edges, key=lambda e: plan.g.edges[e]["cost"] or 0)
            if _try_close_edge(plan, parent_id, child_id, grid_env):
                continue
            candidates = _get_candidates(plan, parent_id, state, grid_env)
            if not candidates:
                break
            best_sub, _, best_sp = min(candidates, key=lambda x: x[1])
            result = _apply_subgoal(
                plan, parent_id, child_id,
                best_sub, grid_env, self._cnt,
                parent_support_pos=best_sp)
            if result is None:
                break
        for parent_id, child_id in list(plan.open_edges()):
            _try_close_edge(plan, parent_id, child_id, grid_env)
        return plan

## Task 3: Implement V4 — Segment-Node MCTS with Context-Signature Transpositions

**Files:**
- Create: `MCTS/v4.py`

**Spec:** `prompts/algorithms/v4_segment_transpositions.md`

**Key V4 concepts to implement:**

1. **Two-level node structure**: plan nodes hold partial plans; segment nodes are shared via a transposition table.
2. **Segment signature**: `(robot_color, start_pos, goal_pos, context_sig)` where `context_sig = frozenset of (robot_color, position)` for nearby frozen/reserved robots.
3. **Transposition table**: `dict[segment_signature -> SegmentNode]`. Segment nodes accumulate MCTS stats across many plans.
4. **Segment node**: holds subgoal options with footprints and per-option `(visit_count, total_cost)`.
5. **Footprint extraction**: each subgoal option records `{robot: position}` commitments.
6. **Footprint clash detection**: when combining options across segments, check for same robot at different positions. Penalty = relaxed SPL between positions.
7. **Pairwise penalty table**: `(option_i, option_j) -> avg_penalty` accumulated over rollouts.
8. **Pseudo-count initialization**: when a segment node is reused in a new plan, import stats weighted by decay factor.
9. **Two-level backup**: segment-level and plan-level stats updated separately.
10. **UCB at both levels**: plan-level chooses which segment to refine; segment-level chooses which option.

# ---------------------------------------------------------------------------
# V4 Segment nodes and transposition table
# ---------------------------------------------------------------------------

@dataclass
class SegmentOption:
    """A subgoal option within a segment node."""
    subgoal: object  # Subgoal instance
    parent_sp: tuple | None
    footprint: dict  # {robot_color: position}
    visit_count: int = 0
    total_cost: float = 0.0

    @property
    def avg_cost(self):
        if self.visit_count == 0:
            return float("inf")
        return self.total_cost / self.visit_count


@dataclass
class SegmentNode:
    """Shared segment node in the transposition table."""
    signature: tuple
    options: list[SegmentOption] = field(default_factory=list)
    visit_count: int = 0


def _segment_signature(robot_color, start_pos, goal_pos, plan, grid_env, cfg):
    """Build segment signature with context from nearby committed robots."""
    g = plan.g
    context = set()
    for nid, data in g.nodes(data=True):
        if data.get("ntype") in ("support", "bottleneck", "leaf"):
            pos = data.get("pos")
            robot = data.get("robot")
            if pos is not None and robot is not None:
                # Simple proximity: include all committed robots
                # (more sophisticated: filter by grid distance)
                context.add((robot.color, pos))
    return (robot_color, start_pos, goal_pos, frozenset(context))


def _extract_option_footprint(subgoal):
    """Extract {robot_color: position} from subgoal's support/helper."""
    fp = {}
    fp[subgoal.support.color] = subgoal.support.position
    fp[subgoal.helper.color] = subgoal.helper.position
    return fp


def _footprint_clash_penalty(fp1, fp2, grid_env):
    """Compute penalty for footprint overlap between two options."""
    penalty = 0.0
    for color in set(fp1) & set(fp2):
        if fp1[color] != fp2[color]:
            reloc = grid_env.compute_relaxed_shortest_path_length(
                fp1[color], fp2[color])
            if reloc is None:
                return float("inf")
            penalty += reloc
    return penalty

@dataclass
class MCTSNode:
    plan: PartialPlan
    parent: MCTSNode | None
    action: tuple | None
    children: list[MCTSNode] = field(default_factory=list)
    visit_count: int = 0
    total_cost: float = 0.0
    # V4: segment assignments and footprints
    segment_options: dict = field(default_factory=dict)  # {seg_key: SegmentOption}
    footprint_summary: dict = field(default_factory=dict)  # {robot_color: position}

    @property
    def avg_cost(self):
        if self.visit_count == 0:
            return float("inf")
        return self.total_cost / self.visit_count

# MCTS_V4 — Segment-Node MCTS with Context-Signature Transpositions
# ---------------------------------------------------------------------------

class MCTS_V4(MCTS):

    def __init__(self, cfg=None):
        if cfg is None:
            cfg = OmegaConf.load(
                Path(__file__).resolve().parent.parent / "conf" / "v4.yaml")
        self.cfg = cfg

    def solve(self, grid_env: GridEnv, state: State) -> SolveResult:
        self._cnt = _counter()
        self._best_cost = float("inf")
        self._best_plan = None
        self._start_time = time.monotonic()
        self._all_plans = []
        self._iteration = 0
        self._node_count = 0
        self._rollout_count = 0
        self._transposition_table: dict[tuple, SegmentNode] = {}
        self._pairwise_penalties: dict[tuple, tuple] = {}  # (opt_key_i, opt_key_j) -> (total, count)

        root_plan = _build_initial_plan(state, grid_env)
        root = MCTSNode(plan=root_plan, parent=None, action=None)

        for _ in range(self.cfg.max_iterations):
            self._iteration += 1
            node = self._select(root)

            if node.plan.is_complete():
                cost = self._eval_complete(node.plan, grid_env)
                self._backprop(node, cost)
                continue

            child = self._expand(node, grid_env, state)
            if child is None:
                self._backprop(node, self.cfg.penalty_cost)
                continue

            cost = self._rollout(child, grid_env, state)
            self._backprop(child, cost)

        best = (self._best_plan if self._best_plan is not None
                else self._fallback(root, grid_env, state))
        return SolveResult(best_plan=best, all_plans=self._all_plans)

    def _get_or_create_segment_node(self, sig, plan, parent_id, state, grid_env):
        """Look up or create a segment node in the transposition table."""
        if sig in self._transposition_table:
            return self._transposition_table[sig]
        seg_node = SegmentNode(signature=sig)
        # Populate options lazily on first access
        candidates = _get_candidates(plan, parent_id, state, grid_env)
        for subgoal, score, parent_sp in candidates:
            fp = _extract_option_footprint(subgoal)
            seg_node.options.append(SegmentOption(
                subgoal=subgoal, parent_sp=parent_sp, footprint=fp))
        # Sort by score for progressive widening
        seg_node.options.sort(
            key=lambda o: grid_env.subgoal_score(o.subgoal))
        self._transposition_table[sig] = seg_node
        return seg_node

    def _select_segment_option(self, seg_node, existing_footprint, grid_env):
        """UCB1 selection over segment options, with footprint clash penalty."""
        if not seg_node.options:
            return None
        # Progressive widening: only consider first k options
        k = math.ceil(
            self.cfg.pw_C * (max(seg_node.visit_count, 1) ** self.cfg.pw_alpha))
        k = min(k, len(seg_node.options))
        candidates = seg_node.options[:k]

        best_score = float("inf")
        best_opt = None
        for opt in candidates:
            if opt.visit_count == 0:
                return opt  # Explore unvisited first
            exploit = opt.avg_cost
            # Add expected footprint clash penalty
            clash = _footprint_clash_penalty(
                opt.footprint, existing_footprint, grid_env)
            exploit += clash * self.cfg.footprint_clash_penalty_weight
            explore = self.cfg.ucb_exploration * math.sqrt(
                math.log(seg_node.visit_count + 1) / opt.visit_count)
            score = exploit - explore
            if score < best_score:
                best_score = score
                best_opt = opt
        return best_opt

    # -- Selection --

    def _select(self, node: MCTSNode) -> MCTSNode:
        while node.children:
            if self._can_expand(node):
                return node
            viable = [c for c in node.children
                      if c.plan.cost() <= self._best_cost]
            if not viable:
                return node
            node = min(viable, key=lambda c: self._lcb(c, node))
        return node

    def _lcb(self, child, parent):
        if child.visit_count == 0:
            return float("-inf")
        exploit = child.avg_cost
        explore = self.cfg.ucb_exploration * math.sqrt(
            math.log(parent.visit_count + 1) / child.visit_count)
        return exploit - explore

    def _can_expand(self, node):
        k = math.ceil(
            self.cfg.pw_C * (max(node.visit_count, 1) ** self.cfg.pw_alpha))
        return len(node.children) < k

    # -- Expansion --

    def _expand(self, node, grid_env, state):
        plan = node.plan
        open_edges = plan.open_edges()
        if not open_edges:
            return None

        parent_id, child_id = max(
            open_edges, key=lambda e: plan.g.edges[e]["cost"] or 0)

        # V4: look up segment node
        g = plan.g
        parent_data = g.nodes[parent_id]
        child_pos = _get_start_pos(g, child_id)
        robot_color = parent_data.get("robot", g.nodes.get(child_id, {}).get("robot"))
        if robot_color is not None and hasattr(robot_color, 'color'):
            robot_color = robot_color.color
        elif robot_color is None:
            # For goal nodes, use target robot color
            for cid in g.successors(parent_id) if parent_data["ntype"] == "subgoal" else [child_id]:
                r = g.nodes[cid].get("robot")
                if r is not None:
                    robot_color = r.color if hasattr(r, 'color') else r
                    break
            if robot_color is None:
                robot_color = "unknown"

        sig = _segment_signature(
            robot_color, child_pos, parent_data.get("pos"),
            plan, grid_env, self.cfg)
        seg_node = self._get_or_create_segment_node(
            sig, plan, parent_id, state, grid_env)

        if not seg_node.options:
            return None

        # Select option via UCB at segment level
        opt = self._select_segment_option(
            seg_node, node.footprint_summary, grid_env)
        if opt is None:
            return None

        tried = {c.action for c in node.children}
        subgoal = opt.subgoal
        parent_sp = opt.parent_sp
        action_key = (parent_id, child_id,
                      subgoal.bottleneck.position,
                      subgoal.support.position,
                      subgoal.helper.color,
                      parent_sp)
        if action_key in tried:
            # Try other options
            k = math.ceil(
                self.cfg.pw_C * (max(seg_node.visit_count, 1) ** self.cfg.pw_alpha))
            for o in seg_node.options[:min(k, len(seg_node.options))]:
                ak = (parent_id, child_id,
                      o.subgoal.bottleneck.position,
                      o.subgoal.support.position,
                      o.subgoal.helper.color,
                      o.parent_sp)
                if ak not in tried:
                    opt = o
                    subgoal = o.subgoal
                    parent_sp = o.parent_sp
                    action_key = ak
                    break
            else:
                return None

        child_plan = _copy_plan(plan)
        result = _apply_subgoal(
            child_plan, parent_id, child_id,
            subgoal, grid_env, self._cnt,
            parent_support_pos=parent_sp)
        if result is None:
            return None

        for pid, cid in list(child_plan.open_edges()):
            _try_close_edge(child_plan, pid, cid, grid_env)

        # V4: update footprint summary
        child_fp = dict(node.footprint_summary)
        child_fp.update(opt.footprint)

        child_seg_opts = dict(node.segment_options)
        child_seg_opts[(parent_id, child_id)] = opt

        child_node = MCTSNode(
            plan=child_plan, parent=node, action=action_key,
            segment_options=child_seg_opts,
            footprint_summary=child_fp)
        self._node_count += 1
        node.children.append(child_node)
        self._check_complete(child_plan, grid_env)
        return child_node

    # -- Rollout --

    def _rollout(self, node, grid_env, state):
        self._rollout_count += 1
        plan = _copy_plan(node.plan)
        footprint = dict(node.footprint_summary)
        segment_opts_used = dict(node.segment_options)

        for _ in range(self.cfg.max_rollout_depth):
            for pid, cid in list(plan.open_edges()):
                _try_close_edge(plan, pid, cid, grid_env)

            open_edges = plan.open_edges()
            if not open_edges:
                break

            parent_id, child_id = random.choice(open_edges)

            candidates = _get_candidates(plan, parent_id, state, grid_env)
            if not candidates:
                return self.cfg.penalty_cost

            # Score with footprint clash penalty
            scored = []
            for subgoal, score, parent_sp in candidates:
                fp = _extract_option_footprint(subgoal)
                clash = _footprint_clash_penalty(fp, footprint, grid_env)
                scored.append((subgoal, score + clash, parent_sp, fp))

            scored.sort(key=lambda x: x[1])
            pick_from = max(1, len(scored) // 2)
            subgoal, _, parent_sp, fp = random.choice(scored[:pick_from])

            result = _apply_subgoal(
                plan, parent_id, child_id,
                subgoal, grid_env, self._cnt,
                parent_support_pos=parent_sp)
            if result is None:
                continue

            footprint.update(fp)

        for pid, cid in list(plan.open_edges()):
            _try_close_edge(plan, pid, cid, grid_env)

        total_cost = self.cfg.penalty_cost
        if plan.is_complete():
            self._check_complete(plan, grid_env)
            cost = evaluate_plan(plan, grid_env)
            if cost is not None:
                total_cost = cost

                # V4: two-level backup — update segment options
                for seg_key, opt in segment_opts_used.items():
                    opt.visit_count += 1
                    opt.total_cost += cost
        else:
            total_cost = plan.cost()

        return total_cost

    # -- Backpropagation --

    def _backprop(self, node, cost):
        while node is not None:
            node.visit_count += 1
            node.total_cost += cost
            node = node.parent

    # -- Helpers --

    def _eval_complete(self, plan, grid_env):
        cost = evaluate_plan(plan, grid_env)
        if cost is not None:
            if cost < self._best_cost:
                self._best_cost = cost
                self._best_plan = _copy_plan(plan)
            self._all_plans.append(PlanEntry(
                plan=_copy_plan(plan), cost=cost,
                stats=PlanStats(
                    wall_time=time.monotonic() - self._start_time,
                    iteration=self._iteration,
                    node_count=self._node_count,
                    rollout_count=self._rollout_count)))
            return cost
        return self.cfg.penalty_cost

    def _check_complete(self, plan, grid_env):
        if plan.is_complete():
            self._eval_complete(plan, grid_env)

    def _fallback(self, root, grid_env, state):
        best_node = root
        stack = [root]
        while stack:
            n = stack.pop()
            if n.visit_count > 0 and n.avg_cost < best_node.avg_cost:
                best_node = n
            stack.extend(n.children)
        plan = _copy_plan(best_node.plan)
        for _ in range(self.cfg.max_rollout_depth):
            open_edges = plan.open_edges()
            if not open_edges:
                break
            parent_id, child_id = max(
                open_edges, key=lambda e: plan.g.edges[e]["cost"] or 0)
            if _try_close_edge(plan, parent_id, child_id, grid_env):
                continue
            candidates = _get_candidates(plan, parent_id, state, grid_env)
            if not candidates:
                break
            best_sub, _, best_sp = min(candidates, key=lambda x: x[1])
            result = _apply_subgoal(
                plan, parent_id, child_id,
                best_sub, grid_env, self._cnt,
                parent_support_pos=best_sp)
            if result is None:
                break
        for parent_id, child_id in list(plan.open_edges()):
            _try_close_edge(plan, parent_id, child_id, grid_env)
        return plan
```

## Task 4: Implement V5 — Nested (Two-Stage) MCTS: Skeleton First, Realization Second

**Files:**
- Create: `MCTS/v5.py`

**Spec:** `prompts/algorithms/v5_nested_two_stage.md`

**Key V5 concepts to implement:**

1. **Outer MCTS** searches over **plan skeletons** — all subgoal assignments chosen but edges potentially open (exact costs not computed).
2. **Inner search** takes a complete skeleton and tries to **realize** it: compute exact shortest paths for all edges, detect conflicts.
3. **Conflict feedback**: when inner search reports a conflict set, outer MCTS records it and penalizes future skeletons containing the same conflicting subgoal pairs.
4. **Greedy skeleton completion**: for outer rollouts, greedily complete partial skeletons then inner-evaluate.
5. **Inner SPL cache**: cache `compute_exact_shortest_path_length` results (deterministic).
6. **Inner local repair**: if an edge is unreachable, try swapping support robot.
7. **Conflict constraint set**: set of conflict sets at each outer node; filters/penalizes future extensions.
8. **Skeleton signature**: frozenset of subgoal assignments for transposition.
9. **Pruning**: if partial skeleton relaxed cost exceeds best realized cost, prune.

def _realize_skeleton(plan, grid_env, state, cfg, spl_cache=None):
    """Attempt to realize a skeleton by fixing all open edges.

    Returns (realized_plan, cost, conflict_set).
    - cost is float (exact cost) or None if unrealizable
    - conflict_set is a frozenset of subgoal assignment tuples that caused failure
    """
    if spl_cache is None:
        spl_cache = {}

    plan = _copy_plan(plan)  # Work on a copy
    g = plan.g

    # Try to fix all open edges in topological order (leaves to goal)
    try:
        topo = list(nx.topological_sort(g))
    except nx.NetworkXUnfeasible:
        return plan, None, frozenset()

    # Reverse topo: process children before parents
    topo.reverse()

    conflict_subgoals = set()

    for node_id in topo:
        for parent_id in list(g.predecessors(node_id)):
            edge_data = g.edges.get((parent_id, node_id))
            if edge_data is None or edge_data.get("status") != "open":
                continue

            # Try to close this edge
            closed = _try_close_edge(plan, parent_id, node_id, grid_env)
            if closed:
                continue

            # Try local repair: find the subgoal that created this segment
            # and try alternative support robots
            if cfg.inner_max_repair_attempts > 0:
                repaired = _try_local_repair(
                    plan, parent_id, node_id, grid_env, state,
                    cfg.inner_max_repair_attempts, spl_cache)
                if repaired:
                    continue

            # Find which subgoal nodes are ancestors of this edge
            for anc in nx.ancestors(g, parent_id):
                if g.nodes[anc].get("ntype") == "subgoal":
                    sg_data = g.nodes[anc]
                    # Build subgoal signature from children
                    bn_pos = sp_pos = helper_color = None
                    for ch in g.successors(anc):

                    conflict_subgoals.add((bn_pos, sp_pos, helper_color))

            return plan, None, frozenset(conflict_subgoals)

    cost = evaluate_plan(plan, grid_env)

# ---------------------------------------------------------------------------
# MCTS_V5 — Nested (Two-Stage) MCTS
# ---------------------------------------------------------------------------

class MCTS_V5(MCTS):

    def __init__(self, cfg=None):
        if cfg is None:
            cfg = OmegaConf.load(
                Path(__file__).resolve().parent.parent / "conf" / "v5.yaml")
        self.cfg = cfg

    def solve(self, grid_env: GridEnv, state: State) -> SolveResult:
        self._cnt = _counter()
        self._best_cost = float("inf")
        self._best_plan = None
        self._start_time = time.monotonic()
        self._all_plans = []
        self._iteration = 0
        self._node_count = 0
        self._rollout_count = 0
        self._spl_cache = {} if self.cfg.inner_spl_cache else None
        self._global_conflicts: list[frozenset] = []

        root_plan = _build_initial_plan(state, grid_env)
        root = MCTSNode(plan=root_plan, parent=None, action=None)

        for _ in range(self.cfg.max_iterations):
            self._iteration += 1
            node = self._select(root)

            if node.plan.is_complete():
                cost = self._eval_via_inner(node, grid_env, state)
                self._backprop(node, cost)
                continue

            child = self._expand(node, grid_env, state)
            if child is None:
                self._backprop(node, self.cfg.penalty_cost)
                continue

            cost = self._rollout(child, grid_env, state)
            self._backprop(child, cost)

        best = (self._best_plan if self._best_plan is not None
                else self._fallback(root, grid_env, state))
        return SolveResult(best_plan=best, all_plans=self._all_plans)

    def _conflict_penalty(self, subgoal_assignments):
        """Compute penalty based on how many known conflicts this skeleton triggers."""
        penalty = 0.0
        for cs in self._global_conflicts:
            if cs.issubset(subgoal_assignments):
                penalty += self.cfg.conflict_penalty_weight
        return penalty

    def _eval_via_inner(self, node, grid_env, state):
        """Run inner realization on a complete skeleton."""
        realized_plan, cost, conflicts = _realize_skeleton(
            node.plan, grid_env, state, self.cfg, self._spl_cache)
        if conflicts:
            node.conflict_sets.add(conflicts)
            self._global_conflicts.append(conflicts)
            # Propagate conflicts upward
            p = node.parent
            while p is not None:
                p.conflict_sets.add(conflicts)
                p = p.parent
        if cost is not None:
            if cost < self._best_cost:
                self._best_cost = cost
                self._best_plan = _copy_plan(realized_plan)
            self._all_plans.append(PlanEntry(
                plan=_copy_plan(realized_plan), cost=cost,
                stats=PlanStats(
                    wall_time=time.monotonic() - self._start_time,
                    iteration=self._iteration,
                    node_count=self._node_count,
                    rollout_count=self._rollout_count)))
            return cost
        return self.cfg.penalty_cost

    # -- Selection --

    def _select(self, node):
        while node.children:
            if self._can_expand(node):
                return node
            viable = [c for c in node.children
                      if c.plan.cost() <= self._best_cost]
            if not viable:
                return node
            node = min(viable, key=lambda c: self._lcb(c, node))
        return node

    def _lcb(self, child, parent):
        if child.visit_count == 0:
            return float("-inf")
        exploit = child.avg_cost
        # V5: add conflict penalty
        exploit += self._conflict_penalty(child.subgoal_assignments)
        explore = self.cfg.ucb_exploration * math.sqrt(
            math.log(parent.visit_count + 1) / child.visit_count)
        return exploit - explore

    def _can_expand(self, node):
        k = math.ceil(
            self.cfg.pw_C * (max(node.visit_count, 1) ** self.cfg.pw_alpha))
        return len(node.children) < k

    # -- Expansion --

    def _expand(self, node, grid_env, state):
        plan = node.plan
        open_edges = plan.open_edges()
        if not open_edges:
            return None

        parent_id, child_id = max(
            open_edges, key=lambda e: plan.g.edges[e]["cost"] or 0)

        candidates = _get_candidates(plan, parent_id, state, grid_env)
        if not candidates:
            return None

        # V5: penalize candidates that would trigger known conflicts
        scored_candidates = []
        for subgoal, score, parent_sp in candidates:
            sg_sig = (subgoal.bottleneck.position,
                      subgoal.support.position,
                      subgoal.helper.color)
            trial_assignments = node.subgoal_assignments | {sg_sig}
            conflict_pen = self._conflict_penalty(trial_assignments)
            scored_candidates.append(
                (subgoal, score + conflict_pen, parent_sp, sg_sig))

        scored_candidates.sort(key=lambda x: x[1])

        tried = {c.action for c in node.children}
        for subgoal, _score, parent_sp, sg_sig in scored_candidates:
            action_key = (parent_id, child_id,
                          subgoal.bottleneck.position,
                          subgoal.support.position,
                          subgoal.helper.color,
                          parent_sp)
            if action_key in tried:
                continue

            child_plan = _copy_plan(plan)
            result = _apply_subgoal(
                child_plan, parent_id, child_id,
                subgoal, grid_env, self._cnt,
                parent_support_pos=parent_sp)
            if result is None:
                continue

            for pid, cid in list(child_plan.open_edges()):
                _try_close_edge(child_plan, pid, cid, grid_env)

            # V5: pruning — if relaxed cost already exceeds best
            if self.cfg.skeleton_pruning and child_plan.cost() > self._best_cost:
                continue

            child_assignments = node.subgoal_assignments | {sg_sig}

            child_node = MCTSNode(
                plan=child_plan, parent=node, action=action_key,
                subgoal_assignments=child_assignments)
            self._node_count += 1
            node.children.append(child_node)

            # If complete, immediately evaluate via inner search
            if child_plan.is_complete():
                self._eval_via_inner(child_node, grid_env, state)

            return child_node

        return None

    # -- Rollout (greedy skeleton completion + inner evaluation) --

    def _rollout(self, node, grid_env, state):
        self._rollout_count += 1
        plan = _copy_plan(node.plan)

        # Greedy skeleton completion
        for _ in range(self.cfg.max_rollout_depth):
            for pid, cid in list(plan.open_edges()):
                _try_close_edge(plan, pid, cid, grid_env)

            open_edges = plan.open_edges()
            if not open_edges:
                break

            parent_id, child_id = max(
                open_edges, key=lambda e: plan.g.edges[e]["cost"] or 0)

            candidates = _get_candidates(plan, parent_id, state, grid_env)
            if not candidates:
                return self.cfg.penalty_cost

            # Greedy: pick best score
            candidates.sort(key=lambda x: x[1])
            subgoal, _, parent_sp = candidates[0]

            result = _apply_subgoal(
                plan, parent_id, child_id,
                subgoal, grid_env, self._cnt,
                parent_support_pos=parent_sp)
            if result is None:
                # Try next candidate
                applied = False
                for sg, _, psp in candidates[1:]:
                    result = _apply_subgoal(
                        plan, parent_id, child_id,
                        sg, grid_env, self._cnt,
                        parent_support_pos=psp)
                    if result is not None:
                        applied = True
                        break
                if not applied:
                    return self.cfg.penalty_cost

        for pid, cid in list(plan.open_edges()):
            _try_close_edge(plan, pid, cid, grid_env)

        if not plan.is_complete():
            return plan.cost()

        # V5: inner evaluation
        realized_plan, cost, conflicts = _realize_skeleton(
            plan, grid_env, state, self.cfg, self._spl_cache)
        if conflicts:
            self._global_conflicts.append(conflicts)
            # Propagate to the node
            p = node
            while p is not None:
                p.conflict_sets.add(conflicts)
                p = p.parent
        if cost is not None:
            if cost < self._best_cost:
                self._best_cost = cost
                self._best_plan = _copy_plan(realized_plan)
            self._all_plans.append(PlanEntry(
                plan=_copy_plan(realized_plan), cost=cost,
                stats=PlanStats(
                    wall_time=time.monotonic() - self._start_time,
                    iteration=self._iteration,
                    node_count=self._node_count,
                    rollout_count=self._rollout_count)))
            return cost

        return self.cfg.penalty_cost

    # -- Backpropagation --

    def _backprop(self, node, cost):
        while node is not None:
            node.visit_count += 1
            node.total_cost += cost
            node = node.parent

    # -- Fallback --

    def _fallback(self, root, grid_env, state):
        best_node = root
        stack = [root]
        while stack:
            n = stack.pop()
            if n.visit_count > 0 and n.avg_cost < best_node.avg_cost:
                best_node = n
            stack.extend(n.children)
        plan = _copy_plan(best_node.plan)
        for _ in range(self.cfg.max_rollout_depth):
            open_edges = plan.open_edges()
            if not open_edges:
                break
            parent_id, child_id = max(
                open_edges, key=lambda e: plan.g.edges[e]["cost"] or 0)
            if _try_close_edge(plan, parent_id, child_id, grid_env):
                continue
            candidates = _get_candidates(plan, parent_id, state, grid_env)
            if not candidates:
                break
            best_sub, _, best_sp = min(candidates, key=lambda x: x[1])
            result = _apply_subgoal(
                plan, parent_id, child_id,
                best_sub, grid_env, self._cnt,
                parent_support_pos=best_sp)
            if result is None:
                break
        for parent_id, child_id in list(plan.open_edges()):
            _try_close_edge(plan, parent_id, child_id, grid_env)
        return plan
```

## Implementation Notes

### Shared helpers
Each v{N}.py copies the helper functions verbatim from v1.py. This keeps versions fully independent. The helpers are:
- `_counter`, `_copy_plan`
- `_find_sibling_support_pos`, `_find_sibling_support_robot`
- `_get_start_pos`, `_build_initial_plan`
- `_build_segment_states`, `_get_ancestor_positions`
- `_get_candidates`, `_apply_subgoal`, `_try_close_edge`

### Key differences between versions at a glance

| Feature | V3 | V4 | V5 |
|---------|----|----|-----|
| Constraint store | Yes (BlockReq, ProtectReq, SupportReq) | No | No |
| No-good table | Yes (context-specific) | No | No |
| Backjumping | Yes (during rollout) | No | No |
| Transposition table | No | Yes (segment-level) | No |
| Footprint tracking | No | Yes (per segment option) | No |
| Two-level search | No | Yes (plan + segment) | Yes (outer skeleton + inner realization) |
| Conflict feedback | Via no-goods | Via clash penalties | Via conflict sets (inner -> outer) |
| Dead node detection | Yes | No | No |
